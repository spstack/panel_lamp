# Instrument Panel Lamp

I got this old instrument panel out of a printing press that was (unfortunately) being scrapped.
Decided to make it into a cool looking lamp so it's not only a neat display, but also somewhat functional.

<img src="images/panel-lamp2.jpg" alt="The finished instrument panel lamp" width="400">
<img src="images/panel-lamp3.jpg" alt="The finished instrument panel lamp" width="400">

I'm honestly not sure what the panel controlled on the old printing press, but it's pretty cool looking and
has some super satisfying switches to press.

It uses all of the original knobs and buttons to control various aspects of the lamp.

The toggle switch in the center is the main on/off switch for the whole thing. It's wired through one
of the fuses on the front panel as well.

The left knob controls the brightness of the main lamp bulb. It's an autotransformer, so it can just
be directly hooked up to the bulb to control brightness.

The other switches/knobs are tied to an arduino that controls back-lighting LEDs
